# Gestor-de-Tareas
Desarrollar una aplicación web denominada Gestor de Tareas, que permita al usuario registrar actividades y administrarás directamente desde la interfaz, sin recargar la página.
La aplicación deberá permitir:
* Agregar nuevas tareas.
* Marcar tareas como completadas.
* Eliminar tareas.
* Visualizar el número de tareas pendientes.
* Actualizar dinámicamente la interfaz mediante JavaScript.
